# Dynamic Task Manager

## 📌 Project Description
This is a simple JavaScript Task Manager application built as part of the NeXTStack Full Stack Cohort at Mississippi Coding Academy.

Users can:
- Add tasks
- View tasks in the console
- Delete a specific task
- Clear all tasks

---

## 🚀 Features

### 1. Add Task
- Adds a new task using `.push()`
- Displays tasks using a `for...of` loop

### 2. Numbered List
- Displays tasks with numbers using a classic `for` loop

### 3. Delete Specific Task
- Removes a task using the **collector pattern**
- Uses `if` condition + `for...of` loop

### 4. Clear All Tasks
- Uses a `while` loop + `.pop()` to empty the array
